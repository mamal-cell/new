# Electruck

نمونهٔ اولیهٔ اپ اندروید تخصصی برای مدیریت نقشه‌ها و پروژه‌های برق خودرو. این پروژه با Kotlin و Jetpack Compose ساخته شده و نقطهٔ شروع محصول است، نه نسخهٔ آمادهٔ انتشار.

## اجرای پروژه

1. پروژه را در Android Studio باز کنید.
2. از نصب بودن JDK سازگار و Android SDK 35 مطمئن شوید.
3. Gradle Sync را اجرا و سپس پیکربندی `app` را روی شبیه‌ساز یا دستگاه اندرویدی اجرا کنید.

حداقل نسخهٔ اندروید: Android 8.0 (API 26). شناسهٔ اپ: `com.madarban.app`.

## آنچه در نمونهٔ فعلی پیاده‌سازی شده

- داشبورد فارسی و چیدمان راست‌به‌چپ
- صفحه‌های خانه، آرشیو پروژه‌ها، میز تحلیل و تنظیمات
- کارت‌های نمونهٔ خودرو، نمای شماتیک نمایشی و مثال کد فیوز `F 43 15A`
- جابه‌جایی بین تب‌ها، نمایش جزئیات نمونه و کلید تم تیره
- نمایش مفهوم دسترسی تخصصی و تأیید کاربر توسط مالک

## آنچه هنوز نمونه/جایگزین است

داده‌ها و پروژه‌ها فعلاً نمونه و ثابت‌اند. بارگذاری و پردازش واقعی نقشه، OCR و تشخیص نماد، ورود Google، پایگاه داده، دعوت و مدیریت نقش کاربران، سرویس هوش مصنوعی، مکالمه و تبدیل متن به گفتار هنوز به بک‌اند و پیاده‌سازی جداگانه نیاز دارند. هیچ تحلیل نمایشی را نباید نتیجهٔ فنی واقعی یا توصیهٔ قطعی تعمیر دانست.

## گام‌های بعدی پیشنهادی

1. طراحی مدل دادهٔ خودرو، نقشه، مدار، یادداشت و دسترسی کاربر.
2. افزودن انتخاب تصویر/PDF با Android Photo Picker و ذخیرهٔ امن فایل.
3. پیاده‌سازی لایهٔ OCR با امکان بازبینی و اصلاح نتیجه توسط متخصص.
4. ساخت ورود Google و نقش مالک/کاربر تأییدشده در Firebase یا بک‌اند اختصاصی.
5. افزودن تحلیل هوشمند پشت API امن، سپس گفتار و آزمون‌های خودکار.

مالک باید بتواند درخواست هر کاربر را تأیید یا رد کند، دسترسی را لغو کند و هر پروژه را به‌صورت پیش‌فرض خصوصی نگه دارد. راهنمای تعمیر نیز باید محدودیت‌ها و هشدارهای ایمنی را روشن کند.
